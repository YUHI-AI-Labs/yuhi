# ADR-0001: Record architecture decisions

Date: 2026-07-24 · Status: Accepted

## Context
Yuhi is a security-adjacent OSS tool where design rationale matters for reviewers and
future contributors.

## Decision
Use lightweight ADRs (Michael Nygard format) in `docs/adr/`. One decision per file,
numbered. Status is one of Proposed / Accepted / Superseded.

## Consequences
Decisions are traceable; superseding is explicit rather than silent edits.
